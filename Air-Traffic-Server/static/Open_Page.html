Phone can't connect?
  1. Put the phone on the same Wi-Fi as this computer. Turn off mobile data, and don't use a guest network.
  2. Allow Python through the firewall. On Windows: Start → "Allow an app through Windows Firewall" → Change settings → tick Private (and Public if your Wi-Fi is marked Public) for every Python entry.
  3. On the phone, type the address exactly as shown, starting with http:// (not https).
  4. This computer has more than one network address. If one doesn't work, pick another to update the QR code:
  5. Turn off any VPN on this computer or the phone.
